# Known limitations

- First-time human usability, enjoyment and campaign length have not been established. Guided test timings are not human play times.
- Art is a compact procedural indie style. Terrain, foliage and feedback still have room for improvement.
- Native game audio has been decoded and checked for level/headroom, but no human listening review is claimed.
- Godot 4.5.2 can report audio playback resources during immediate debug shutdown. An increasing runtime leak has not been established.
- Windows export has not been run on Windows. Linux has not been playtested. Phones and gamepads are not supported by the current control scheme.
- Save compatibility across community revisions is not guaranteed. Back up an important campaign before testing a modified build.
- The mining, geology, support rules and recipes are fictional gameplay systems, not real-world mining guidance.
